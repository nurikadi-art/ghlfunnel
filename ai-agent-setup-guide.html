Part 1: Moltbot on VPS

Moltbot (now called OpenClaw) is an open-source AI agent that runs autonomously on a server. Unlike chatbots that just generate text, Moltbot can execute commands, manage files, automate browsers, and complete tasks — all without you being there.

💡 Why Moltbot is Different

Regular AI chatbots advise. Moltbot acts. It's like having a digital employee that works 24/7 on a remote computer, completing tasks while you sleep.

⚠️ CRITICAL: Never Install on Your Personal Computer

Moltbot requires high-level system access to work. Installing it on your personal machine is a serious security risk. Always use a VPS (Virtual Private Server) instead.

  • A VPS isolates Moltbot from your personal files
  • If something goes wrong, only the VPS is affected
  • VPS runs 24/7 without leaving your home computer on
  • Better security: firewall rules, Docker isolation, non-root execution

Setting Up Moltbot on Hostinger VPS

Requirements

  • 💳 Hostinger VPS account (~$4.99/month for entry tier)
  • 🔑 Anthropic API key (for Claude) or OpenAI API key
  • 💬 Discord or Telegram account (to communicate with your agent)
  • ⏱️ About 30 minutes to complete setup
1

Get Your Hostinger VPS

Go to hostinger.com and purchase a VPS plan.

  • Choose the KVM 1 plan (minimum) — 4GB RAM is recommended
  • Select Ubuntu 22.04 as your operating system
  • Choose a data center location close to you
  • Complete the purchase and wait for setup (usually 2-5 minutes)
2

Connect to Your VPS

Once your VPS is ready, you'll get an IP address and root password.

  • On Mac/Linux: Open Terminal
  • On Windows: Download and open PuTTY or use Windows Terminal
  • Connect using the command below:
Terminal Command ssh root@YOUR_VPS_IP_ADDRESS

Enter your password when prompted. You're now connected to your VPS.

3

Install Docker

Moltbot runs inside Docker for security. Run these commands one by one:

Update System apt update && apt upgrade -y
Install Docker curl -fsSL https://get.docker.com | sh
Verify Installation docker --version
4

Clone and Run Moltbot

Download Moltbot (OpenClaw) and start the setup:

Clone Repository git clone https://github.com/openclaw/openclaw.git cd openclaw
Run Setup Script ./setup.sh

The setup wizard will guide you through configuration.

5

Configure Your AI Provider

During setup, you'll be asked for your AI API key:

  • Go to console.anthropic.com (for Claude) or platform.openai.com (for GPT)
  • Navigate to API Keys
  • Create a new key and copy it
  • Paste it into the setup wizard when prompted

🔐 Keep Your API Key Secret

Never share your API key. Anyone with it can use your account and rack up charges.

6

Connect to Discord/Telegram

Moltbot communicates through messaging platforms. Choose Discord or Telegram:

  • Follow the setup wizard prompts for your chosen platform
  • You'll create a bot token and connect it to your account
  • Once connected, you can DM your bot to give it tasks
7

Start Your Agent

Launch Moltbot:

Start Moltbot docker-compose up -d

Your AI agent is now running 24/7. Message it on Discord/Telegram to give it tasks!

✅ What Moltbot Can Do For You

  • Execute shell commands and scripts automatically
  • Manage files (create, edit, organize, backup)
  • Automate browser tasks (research, data scraping, form filling)
  • Run scheduled tasks while you sleep
  • Complete multi-step projects autonomously

💰 Cost Estimate

VPS: ~$5-12/month. API costs vary based on usage — expect $10-50/month for moderate use. Total: roughly $15-60/month for a 24/7 AI agent.

Part 2: Claude Cowork

Claude Cowork is Anthropic's desktop AI agent. Unlike regular Claude chat, Cowork can access your local files, execute multi-step tasks, and work autonomously for hours. You describe what you want, approve the plan, and Claude executes while you do other things.

💡 The Pattern

Chat = thinking together. Cowork = Claude doing work for you. Claude Code = building software. Cowork is for getting real work done without coding.

Requirements

  • 🍎 Mac computer (macOS only — not available on Windows yet)
  • 💳 Paid Claude subscription (Pro, Max, Team, or Enterprise)
  • 📱 Claude Desktop app installed
  • 🌐 Active internet connection throughout the session

How to Use Claude Cowork

1

Download Claude Desktop

Go to claude.ai/download and download the Mac desktop app. Install it like any other app.

2

Open Cowork Mode

  • Open Claude Desktop
  • Look for the mode selector at the top
  • Click the "Cowork" tab (instead of "Chat")
  • The interface will switch to task mode
3

Grant Folder Access

Claude needs permission to access your files. When prompted:

  • Create a dedicated folder: /cowork-workspace
  • Only grant access to specific project folders
  • Never grant access to your entire home directory

🔐 Security Best Practice

Create a dedicated workspace folder for Cowork. Don't give it access to sensitive folders like Documents, Downloads, or Desktop.

4

Describe Your Task

Tell Claude what you want done. Be specific:

Example Task "Create a presentation about Q4 sales results. Use the data in /cowork-workspace/sales-data.xlsx. Make it 10 slides with charts. Save as PowerPoint."
5

Review the Plan

Claude will show you its approach before executing:

  • Read through the proposed steps
  • Make sure it understands your intent
  • Ask for changes if needed
  • Click "Approve" to let Claude start working
6

Let Claude Work

Once approved, Claude works autonomously:

  • Keep the Claude Desktop app open (minimize is fine)
  • Go do other work — Claude will keep going
  • Complex tasks can run for minutes or hours
  • Come back to finished work

✅ What Claude Cowork Can Create

  • Excel spreadsheets with working formulas
  • PowerPoint presentations with formatting
  • Organized file structures and folders
  • Research documents with citations
  • Data analysis and reports
  • Any document-based work you can describe

⚡ Pro Tip: Use Plugins

Cowork supports plugins that customize Claude for specific job functions. Check the settings to see available plugins for your workflow.

Part 3: Custom GPT Agents

Custom GPTs are personalized versions of ChatGPT that you create for specific tasks. No coding required. Once built, they remember your instructions, tone, and can access your uploaded documents — ready to use anytime.

💡 Why Build Custom GPTs?

Instead of repeating the same instructions every conversation, build a GPT once and use it forever. Create GPTs for writing emails, analyzing data, customer support, content creation — anything you do repeatedly.

Requirements

  • 💳 ChatGPT Plus, Pro, Team, or Enterprise subscription
  • 🌐 Access to chatgpt.com
  • 📄 Optional: Documents to upload as knowledge base

Creating Your First Custom GPT

1

Access the GPT Builder

  • Go to chatgpt.com and log in
  • Click "Explore GPTs" in the left sidebar
  • Click "Create" in the upper right corner
2

Describe Your GPT

You'll see a split screen: Create panel (left) and Preview panel (right).

In the Create panel, describe what you want:

Example Descriptions "Make a content writer that creates LinkedIn posts in my brand voice" "Create an email assistant that drafts professional responses" "Build a business analyst that reviews financial data"

The GPT Builder will suggest a name, image, and conversation starters.

3

Configure Your GPT

Click the "Configure" tab for detailed settings:

  • Name & Description: What appears when people find your GPT
  • Instructions: Detailed behavior guidelines (the most important part)
  • Conversation Starters: Example prompts to help users begin
  • Knowledge: Upload documents for your GPT to reference
  • Capabilities: Enable web search, image generation, code interpreter
4

Write Powerful Instructions

Instructions are the brain of your GPT. Here's a template:

Instruction Template ## Role You are a [specific role] that helps users [achieve specific outcome]. ## Tone Write in a [professional/casual/friendly] tone. Be [concise/detailed]. ## Process 1. First, ask the user for [required information] 2. Then, [step 2] 3. Finally, [deliver output in specific format] ## Rules - Always [do this] - Never [do that] - When uncertain, [ask for clarification] ## Output Format Deliver responses as [bullet points/paragraphs/structured format].
5

Add Knowledge Files (Optional)

Upload documents your GPT should reference:

  • Brand guidelines and style guides
  • Product documentation
  • Sample outputs you want to emulate
  • Data files, spreadsheets, PDFs

💡 Pro Tip

Upload 10-15 writing samples to train your GPT on your exact tone and style. It's the most effective way to get consistent output.

6

Test in Preview

Use the Preview panel to test your GPT:

  • Try different prompts
  • Check if responses match your expectations
  • Refine instructions based on results
  • Keep testing until it works perfectly
7

Save and Share

Click "Save" and choose who can access:

  • Only me: Private — just for you
  • Anyone with a link: Share with team or clients
  • Everyone: Publish to the GPT Store

Your GPT now appears in your sidebar, ready to use anytime.

✅ Custom GPT Ideas to Build

  • Email Responder: Drafts professional replies in your voice
  • Content Creator: Writes social posts, blogs, newsletters
  • Meeting Summarizer: Turns transcripts into action items
  • Customer Support: Answers FAQs using your knowledge base
  • Data Analyst: Reviews spreadsheets and creates insights
  • Proposal Writer: Generates client proposals from templates

⚡ Best Practice: One GPT, One Purpose

Custom GPTs work best when laser-focused on a single task. Instead of one "do everything" GPT, build multiple specialized GPTs for different workflows.
